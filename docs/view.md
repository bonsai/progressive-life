# View

View is a projection of the current life-story model.

## Primary View

### Episode Field

A non-linear field of Episodes where connections can be visually explored.

### Reader

A person can enter from any Episode and follow Relations.

### History

The system can show how the understanding of an Episode changed as new Relations were confirmed.

## Rule

View is derived. It is not the Canon.

The same history may produce multiple Views without changing the underlying records.
