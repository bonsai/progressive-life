# shitagaki ブランド案

> **いつでもどこでも、ほんの下書きが本の下書きになる。**

## Brand

| 項目 | 内容 |
|---|---|
| ブランド名 | shitagaki（下書き） |
| タグライン | いつでもどこでも、ほんの下書きが本の下書きになる |
| カテゴリ | 声・文章から本を作る自己作成サービス |
| 関係ブランド | progressive-life（エンジン・基盤技術） |

## Concept

shitagaki は、「本を書く」という大きな作業を「下書きをちょこっと残す」に分解するサービス。

- 電車の中で30秒話す
- 寝る前に1分ボイスメモ
- 思い出したことをテキストでサッと書く

これらの「ほんの下書き」が、時間とともに「本の下書き」に育つ。
最終的に、本人の肉声と一緒に紙の本・電子書籍・音声として残せる。

## Positioning

```
progressive-life（技術・世界観）
        ↓
    shitagaki（ブランド・サービス）
        ↓
  ユーザーが「声で本を作る」体験
```

- **progressive-life**: 半生記を作るための基盤技術・世界観
- **shitagaki**: その技術を使った、気軽に始められる消費者向けブランド

## Target

- 半生記を残したいが「文章を書く」時間がない人
- 親や祖父母の声を残したい家族
- 日々の思い出をかたちにしたい人
- 従来の自分史サービス（3.5万円〜）では手が出ない人

## User Flow

```
1. 気軽に下書きを残す
   └── 音声（ボイスメモ） or テキスト or 写真

2. AIが「本の下書き」に整える
   └── STT → エピソードカード → 時系列/人物/場所タグ

3. 本人がカードを並べ替え・確認
   └── 間違いを直す、関係をつける、不要なものを外す

4. 自動で本を生成
   └── 紙の本 / 電子書籍 / 音声データ
```

## Key Difference

| 既存サービス | shitagaki |
|---|---|
| 一度きりのインタビュー | 日常の「ほんの下書き」の積み重ね |
| 業者が書く | 本人が話す・並べる・確認する |
| 高額な自分史プラン | 低価格・小さく始められる |
| 本だけが成果物 | **本 + 元になった本人の肉声** |

## Naming Rationale

「下書き」は、完成を急がず、まず形に残す行為。
完璧でなくてよい。続ければ、いつの間にか本の下書きになる。

英字表記: `shitagaki`（ローマ字）。
親しみやすさと、「下書き」という意味がそのまま残る。

## Price Image

- 小さく始められる: 無料 or 月額数百円
- 本生成: 1,000円〜3,000円帯を目安
- 目標: 200ページ・1,000円という衝撃的な低価格帯
