# 自費出版サービス市場調査：声で残す半生記

> **1行要約**: 「本人が話す → 文字化 → 本にする」市場は既に成立しており、progressive-life は「取材型自分史」ではなく「声で作る自分史OS」として差別化できる。

## Status

- 調査日: 2025-09-24
- 調査対象: 日本国内の自分史・自費出版サービス
- 目的: progressive-life のポジショニングと価格帯・販売経路の選定

## 近い既存サービス

| サービス | 方式 | 料金の目安 | 特徴 |
|---|---:|---|---|
| ヒストリーズ | 話す → 編集 → 本 | 35,000円〜 | 100ページPDF 35,000円、100ページ10冊 205,000円 |
| VIVREEL | インタビュー → 文章/小説 | 60,000円〜 | 3時間程度のインタビュー、文字起こし |
| 一代記 | スマホで自分で録音 → AI＋人 → 本 | 要確認 | **今回の構想にかなり近い** |
| officeSAYA | インタビュー → 文字起こし → 本 | 60,000円〜 | 2時間プラン、3冊 |
| 自分史・記念誌出版会 | インタビュー → 執筆 → 出版 | 1万円/取材1h＋印刷等 | 本格的な自費出版 |
| 木村文章店「人生記」 | 取材 → 音声/文章/本 | 55,000円〜 | 音声データだけの納品も可能 |

### 特に注目：一代記

「話す → 文章にする → 一冊にする → 残し続ける」という構造。
本人がスマホのボイスメモに吹き込むところから始まる。
progressive-life の構想と強く重なる。

## 既存サービス vs progressive-life

### 既存サービスの標準フロー

```
インタビュー
  ↓
業者が文字起こし
  ↓
ライターが編集
  ↓
本
```

### progressive-life の構想フロー

```
本人が日常的に声を残す
  ↓
AI STT（例：さくらAI Engine、30分/30MB単位）
  ↓
エピソードカード
  ↓
カードを並べ替える
  ↓
時系列・人物・場所・出来事を整理
  ↓
本人に確認
  ↓
半生記
  ↓
紙の本 ＋ 電子書籍 ＋ 音声
```

### 差別化

| 観点 | 既存サービス | progressive-life |
|---|---|---|
| 起点 | 業者のインタビュー | 本人が日々声を残す |
| 編集権 | ライター/業者 | 本人がカードを並べ替える |
| 音声の扱い | 中間素材 or 別料金 | **原資料として永続保存** |
| 成果物 | 本（+PDF） | 本 + 電子書籍 + **本人の肉声** |
| 価格帯 | 3.5万円〜100万円超 | 低価格・自分史OSとして提供 |

## 価格帯の示唆

- 小規模自分史: 3.5万円〜20万円
- 本格自費出版: 数十万円〜100万円超
- **progressive-life の機会**: 低価格帯で「声を吹き込むだけ」の自己作成型を提供

## 販売戦略：二重経路

### 前提

- 成果物: 200ページ自伝
- 目標価格イメージ: 1,000円 / 1冊

### 販売経路

```
200P自伝
  │
  ├── KDP（Amazon POD）
  │     └── Amazonが注文を受けて印刷・発送
  │
  └── 本人販売（self_sell）
        └── 著者用コピー（印刷原価で購入）
              ↓
        自分のサイト / イベント / 知人 / BASE / etc.
```

### KDP 著者用コピー

- KDP公式に「著者用コピーは再販できる」と明記
- 自分で在庫を持ち、サイトやイベントで販売可能

### BASE などの活用

- 紙の商品販売に対応
- PDFなどデジタルコンテンツ販売も可能

### Agentが解く構造

```
1冊あたり差益 400円
        ↓
− 送料
− 決済手数料
− 販管費
− その他変動費
        ↓
実質限界利益
        ↓
固定費
        ↓
損益分岐点
        ↓
目標利益に必要な冊数
        ↓
1 / 10 / 50 / 100 / 200 / 500 / 1000冊での感度分析
        ↓
不足データがあれば Issue として質問
```

### 設計上の重要点

- 「最適冊数」を勝手に決めない
- 需要・販売上限・固定費などの制約がなければ、利益が正の限り有限最適値は存在しない
- 数学的成立条件を判定し、次に必要なデータを Issue 化する
