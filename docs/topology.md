# Topology

progressive-life のEntityがどう接続し、変化するかを定義する。

## Core Flow

Voice → Episode → Event → Decision → Candidate Relation → Human Confirmation → Relation → View

## SVO

Eventは基本的に、

Subject → Action → Object

として表現する。

## World Flow

history → latest → now → action

- history: 蓄積された出来事・判断・関係
- latest: 最新の発見
- now: 現在の状態
- action: 次に語る・つなげる・確認する操作

## Connection

Episode A ─ Relation ─ Episode B

RelationはEpisodeを単に並べるのではなく、別々の記憶を意味的に接続する。

## Human Boundary

AI → Candidate Relation → Human Confirmation → Historical Relation

AIの推測と本人が認めた関係を分離する。
