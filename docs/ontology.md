# Ontology

progressive-life に存在する基本的なものを定義する。

## Entities

- Voice — 本人が語った原音声
- Episode — Voiceから切り出された人生の断片
- Event — 起きたこと・観測されたこと
- Decision — 判断・意味づけ
- Relation — Entity間のつながり
- View — 現在の理解を投影した表示
- Person / Entity — EventやRelationの主体・対象

## Derived Order

Voice → Episode → Event → Decision → Relation → View

Ontologyは「何が存在し、それは何か」を定義する。接続や流れはTopologyで定義する。
